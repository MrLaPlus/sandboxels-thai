# มอดภาษาไทยสำหรับ Sandboxels

มอดภาษาไทยสำหรับ [Sandboxels](https://store.steampowered.com/app/3664820) บน Steam ทำไว้กับเนื้อหาเกมรุ่น **1.15**

แปลชื่อธาตุ ชื่อหมวด ปุ่ม เมนูเซฟ หน้าตั้งค่า และข้อความสั้นๆ ในเกม ไฟล์มอดฝังฟอนต์ไทยไว้ด้วย อ่านได้แม้เครื่องไม่มีฟอนต์ไทย เซฟยังเก็บรหัสธาตุเป็นภาษาอังกฤษ ค้นคำว่า `sand` ก็ยังเจอทราย

นี่ไม่ใช่ภาษาทางการของเกม ภาษาในเกมบน Steam ยังมาจากเซิร์ฟเวอร์ของผู้พัฒนา มอดนี้ทับข้อความบนเครื่องผู้เล่นเอง

## ติดตั้ง

ใส่ไฟล์เดียวคือ `thai.js` เข้าโฟลเดอร์มอดของเกม ห้ามก็อปทั้งโฟลเดอร์นี้เข้าไป เกมจะพยายามรันทุกไฟล์ในนั้นเป็นสคริปต์ แล้วเกมจะเปิดไม่ขึ้น

1. ปิดเกมให้หมด
2. รันสคริปต์ในโฟลเดอร์นี้
   - Linux: `sh ติดตั้ง.sh`
   - Windows: ดับเบิลคลิก `ติดตั้ง.bat`
3. เปิดเกมใหม่

เกมอ่านรายชื่อมอดตอนเปิดครั้งเดียว รันสคริปต์ตอนเกมเปิดอยู่จะไม่เปลี่ยนภาษาในรอบนั้น

สคริปต์เขียนทับเฉพาะ `mods/thai.js` ไม่ลบมอดอื่น และไม่แตะเซฟ

### วางไฟล์เอง

| เครื่อง | ที่วาง |
| --- | --- |
| Windows | `%APPDATA%\sandboxels\mods\thai.js` |
| Linux ตัวเกมเป็นโปรแกรมลินุกซ์ | `~/.local/share/sandboxels/mods/thai.js` |
| Steam แบบ Flatpak และตัวเกมเป็นโปรแกรมลินุกซ์ | `~/.var/app/com.valvesoftware.Steam/.local/share/sandboxels/mods/thai.js` |
| Linux ที่เปิด `Sandboxels.exe` ผ่าน Proton | `.../steamapps/compatdata/3664820/pfx/drive_c/users/steamuser/AppData/Roaming/sandboxels/mods/thai.js` |

บน Proton สคริปต์ `ติดตั้ง.sh` หา prefix ให้เอง จาก `libraryfolders.vdf` และจากโฟลเดอร์ Steam ที่พบบ่อย เกมรุ่น Windows ไม่อ่าน `~/.local/share/sandboxels`

ในเกม ปุ่ม Clear Saves ของพอร์ต Steam ถูกเปลี่ยนชื่อเป็น Open Data Folder ปุ่มนั้นเปิดโฟลเดอร์ข้อมูลของเกม แล้วเข้า `mods` วาง `thai.js`

## วิธีตรวจว่าติด

เปิดคอนโซลของเครื่องมือนักพัฒนา ถ้ามอดทำงานจะมีบรรทัด

```text
[มอดไทย] ใช้งานแล้ว
```

แถบหมวด ชื่อธาตุ ตั้งค่า และเมนูเซฟเป็นภาษาไทย

มอดทำงานเมื่อภาษาในตั้งค่าเป็นอังกฤษหรือไทย ถ้าเลือกภาษาอื่น มอดจะไม่ทับภาษานั้น ปิดมอดโดยย้าย `thai.js` ออกจากโฟลเดอร์ `mods` แล้วเปิดเกมใหม่

ถ้าเปิดแล้วไม่มีบรรทัดนั้น ให้ปิดเกมแล้วเปิดอีกครั้ง เกมบางจังหวะอ่านโฟลเดอร์มอดไม่ทัน

ทางสำรองด้านล่างจะหายเมื่อกด Verify Integrity ของ Steam

1. วาง `thai.js` ที่ `โฟลเดอร์ติดตั้งเกม/resources/app/mods/thai.js`
2. เปิดเกมครั้งหนึ่ง แล้วปิด
3. ในเครื่องมือนักพัฒนา พิมพ์แล้วกด Enter

```javascript
localStorage.setItem("enabledMods", JSON.stringify(["mods/thai.js"]))
```

4. เปิดเกมใหม่

อย่าพิมพ์ชื่อมอดในช่องเพิ่มมอดของเกม ช่องนั้นจะไปหาไฟล์บนเว็บแทนไฟล์ในเครื่อง

## สิ่งที่ยังเป็นภาษาอังกฤษ

- ประโยคยาวในหน้าข้อมูลธาตุที่เกมประกอบเอง เช่น แตกเป็นอะไร ไหม้ช้าหรือเร็ว
- ชื่อมุมมอง `thermal`, `basic`, `streak`
- ข้อความบันทึกเล็กๆ บางบรรทัด และหน้า changelog
- คำที่เกมเพิ่มหลังรุ่น 1.15 คอนโซลจะเตือนครั้งเดียว
